### 主要特性

- **圆角窗口设计** - 美观的现代化界面
- **多标签页支持** - 高效的标签页管理
- **中文右键菜单** - 完整的中文上下文菜单
- **页面翻译** - 一键翻译网页内容
- **书签管理** - 便捷的书签和历史记录功能
- **快捷键支持** - 丰富的键盘快捷键

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + T | 新建标签页 |
| Ctrl + W | 关闭当前标签页 |
| Ctrl + L | 聚焦地址栏 |
| Ctrl + D | 添加书签 |
| Ctrl + H | 查看历史记录 |
| Ctrl + Shift + B | 查看书签管理 |
| F5 | 刷新页面 |

## 系统要求

- Windows 10 或更高版本
- 无需额外依赖，开箱即用

## 使用说明

1. 下载全部 EXE 分卷。
2. 双击 `merge.bat` 合并安装包。
3. 双击生成的 `StarBrowser_x64_Setup.exe`，按安装向导完成安装。
4. 首次启动会自动创建配置文件。
